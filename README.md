# lurid
AI Hackathon 2025

Task: Build a webapp to help people deal with mental health issues.
Our solution: A webapp that extracts stressors from AI conversation and tabulates them with an action plan.
Stack: HTML, CSS, Python, HuggingFace Transformers, Flask
Time Allotted: 5 days
